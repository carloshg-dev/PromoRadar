# PromoDetec: entrada para agentes

Antes de trabalhar neste repositório:

1. Leia `CLAUDE.md` por inteiro.
2. Leia `MISTAKES.md` e evite reincidências.
3. Confira `docs/PROJECT_STATE.md` para o estado operacional atual.
4. Consulte a skill aplicável em `skills/` antes de repetir um procedimento.
5. Preserve mudanças existentes no working tree e não toque em produção sem aprovação humana explícita.

`CLAUDE.md` é a constituição curta. Procedimentos detalhados pertencem às skills, não a este arquivo.
